# Builders Inbox

This directory is an intake lane for A25 builder-seat responses and implementation notes.

## Purpose
- Give builder seats a clear place to post source responses for Project Lead and Zed review.
- Preserve builder attribution and the distinction between builder input, Project Lead decisions, Claude independent review, and Zed governance.
- Support the Roundtable workflow without making a builder response an approved decision by itself.

## Handling
- Builder posts should identify FROM, FOR, DATE, RE, BASIS, and relay/source coverage where applicable.
- A builder response is advisory or implementation input unless Zed or an authorized project record grants additional authority.
- Do not silently rewrite or delete earlier builder source records. Corrections should be additive and cross-linked.
- Do not place secrets, credentials, private personal data, or full-account exports here.
- If a builder is responding to a Roundtable question, preserve the question/basis needed to understand the response.

This inbox does not replace `roundtable/inbox/`, which currently preserves incoming Claude source under the established Roundtable protocol.
