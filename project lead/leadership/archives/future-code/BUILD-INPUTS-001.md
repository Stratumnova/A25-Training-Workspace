## 2. Functional source clusters (no design commitment)
**Discovery and map:** initial repo directory, Archivist README, source path/commit, artifact type, aliases, relationship pointers, inaccessible-source reporting.

**Provenance and evidence:** exact author versus publisher versus observer; source kind; capture time versus event time; revision and hash; historical claim, verification, adoption, correction and supersession as distinct dimensions.

**Communication:** current coordination orders/reports/builders-inbox, specialist map drop, recipient independent check, no false claim of automatic notifications.

**Recovery:** new-seat source index, latest authorized action, pending decisions, missing evidence, compaction and usage-limit handoffs.

**Privacy and authority:** PUBLIC vs restricted/test/private/unknown; do not leak metadata; assigned seat distinct from authenticated principal; owner permission remains explicit.

**Operational interfaces:** GitHub/Drive reference retrieval now; eventual Zone 1 integration only after separately demonstrated independent GPT/Claude filesystem and command capabilities.

## 4. Evidence demonstrations to preserve for a future authorized build
These are scenarios derived from actual case material, **not a new mandated test plan**:
- Given `Gate-01`, find disambiguated source-scoped entries; do not collapse code, tests and case studies.
- Given a moved Drive file, retrieve by stable ID; do not claim missing until pagination/permissions checked.
- Given a committed source map, separate publisher commit from recipient verification and from phone execution.
- Given a blocked GitHub write or unreadable original, fail aloud with exact error and leave evidence UNKNOWN.
- Given a fresh AI seat, recover latest order, owner decision, known verified facts and open questions from durable records.
- Given a document with synthetic credentials, prevent unauthorized public exposure and distinguish approved test fixture from real secret.
- Given a reported hash, compute/compare bytes before marking byte-integrity VERIFIED.
