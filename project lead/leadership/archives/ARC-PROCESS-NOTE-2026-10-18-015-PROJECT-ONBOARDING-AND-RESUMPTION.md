## Reusable intake/resume workflow
**Identify:** Zed names the project, lead/seat, owner scope and whether this is a new or resumed project; do not guess hidden directives.

**Recover:** Archivist locates original source index, pinned orders, latest reports, adopted decisions, open errors, Watchdog findings and relevant Drive IDs. Mark unavailable material UNKNOWN; avoid presenting old reports as fresh verification.

**Orient:** Archives supplies a source-linked folder map and study guide; new lead confirms seat, reads originals, returns understanding and source-access ledger.

**Reconcile:** Compare the lead's understanding with originals, preserve GPT/Claude conflicts, record accepted decisions separately from test results; refer unresolved conflicts to GPT Project Lead and Zed.

**Handoff:** Lead issues numbered GitHub order, builder returns append-only report with SHA and observable evidence; errors and interim notes go to builders-inbox. Watchdog findings can inform the handoff but do not independently grant approval, permission or implementation authority.

**Resume:** Reconstruct last VERIFIED state, latest ADOPTED decision, current UNKNOWNs, blockers and next owner-authorized action. Never infer deployment or functioning capability from archival acceptance.

## Logging convention
- Every record has FROM, TO/FOR, DATE, BASIS, source IDs, status and scope.
- Record errors when encountered, with exact failed operation, error output, side effects and next step.
- Record decisions when authorized, with rationale and distinction between ADOPTED and VERIFIED.
- Preserve originals and add dated corrections rather than overwriting them.
- GitHub coordination branch: `coord/a25-namespace-trial-001`; formal orders in `project lead/coordination/orders/`, reports in `project lead/coordination/reports/`, interim notes in `project lead/coordination/builders-inbox/`, archive review in `project lead/leadership/archives/`.
- Drive is separate source storage with stable IDs; Claude's existing owner-authorized organizer scope does not automatically extend to other seats. No Drive permission changes implied.
- Never publish secrets or sensitive raw terminal output.
