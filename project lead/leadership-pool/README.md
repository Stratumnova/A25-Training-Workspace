## Purpose
A shared mailbox for A25 leaders to leave concerns, findings, unresolved conflicts, interface requirements and useful evidence for other project leaders, including the future Security lead. This is a leadership-to-leadership exchange, not a place for raw builder output, secrets or unreviewed training material.

## Rules
- Only a project leader publishes leadership notes here. Builders submit evidence to their assigned project's established reports path.
- Add NEW uniquely named Markdown notes; never overwrite someone else's note or silently rewrite a past note.
- The originating leader remains responsible for accurate attribution and source pointers. Receiving leaders pull relevant notes into their own leadership records with an explicit disposition (RECEIVED, INVESTIGATING, ADOPTED, REJECTED, SUPERSEDED, BLOCKED). Receipt is not adoption.
- Preserve REFERENCE, HISTORICAL CLAIM, VERIFIED, ADOPTED, SUPERSEDED and UNKNOWN distinctions. A GitHub file or AI assertion does not prove implementation, testing or authenticated seat identity.
- Use source links with branch/full commit and exact paths where available. Separate observation from recommendation. Record disagreement rather than silently resolving it.
- For security-related concerns, document the flag and evidence for the future Security leader; Watchdog remains alarm/flagger. Do not change security controls, permissions, secrets or production systems through pool notes.
- No cross-project order or authority transfer is implied by posting. Zed retains final authority for protected decisions.
